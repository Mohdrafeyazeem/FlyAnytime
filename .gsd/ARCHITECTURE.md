## Overview
**Fly Anytime** is an ultra-premium bespoke travel and aviation atelier web platform focused on curated luxury journeys, private jet charters, living palace residencies, and heritage rail expeditions across India.

The application is built on modern web standards with zero build step dependencies, leveraging native HTML5, modular CSS3 (Claymorphism & Frosted Glassmorphism design tokens), responsive aspect-ratio media containers, and an asynchronous JavaScript client engine with GPU-accelerated page transitions.

## Components

### 1. Presentation Pages
- **`index.html`**: Main landing hub featuring ambient hero composition, interactive 4-mode booking console, category-filtered itineraries, value pillars, and client testimonials.
- **`flights.html`**: Private aviation fleet showcase (Pilatus PC-24, Challenger 350, AgustaWestland AW109) with charter quotation matrix.
- **`stays.html`**: Curated living palaces (Taj Lake Palace Udaipur, Umaid Bhawan Jodhpur, Rambagh Palace) and royal privileges.
- **`trains.html`**: Sovereign rail expeditions (Maharajas' Express, Palace on Wheels) and itinerary route schedules.
- **`destinations.html`**: High-resolution regional guide (Rajputana, Malabar coast, Himalayan heights).

### 2. Styling System (`css/styles.css`)
- **Tokens**: Curated color scheme rooted in Indian warmth (Primary Saffron `#FF7A00`, Terracotta `#D35400`, Royal Navy `#0D2240`, Sandstone `#FAF8F5`).
- **Claymorphism**: Dual-source elevation shadows creating soft tactile pillowed depth.
- **Glassmorphism**: High-blur translucent panels (`backdrop-filter: blur(16px)`).
- **Responsive Media Wrappers**: `.card-media-wrap` and `.hero-media-wrap` maintaining fluid aspect ratios (`16/10`, `4/3`) with centered object-fit coverage.

### 3. Client Interaction Engine (`js/main.js`)
- **Page Transition System**: Smooth cross-document page exiting/entering states with a luxury glowing top progress bar (`#pageTransitionBar`).
- **Navigation Controllers**: Responsive mobile slide-out drawer, bottom thumb-dock navigation bar, and tab controllers.
- **Form & Modal Engine**: Royal concierge consultation modal with submission feedback.
- **Asset Resiliency**: Automatic error-handling fallback to prevent broken remote imagery.

---

## Data Flow

1. **Initial Load**: Client requests document (`index.html`); styles load synchronously; Google Fonts and Material Symbols load asynchronously; `js/main.js` kicks off entry progress animation.
2. **Page Navigation**: User clicks internal page link; `js/main.js` intercepts, initiates top progress bar sweep, fades out active view, and transitions smoothly to target page.
3. **Inquiry Submissions**: Client triggers "Plan My Trip" or "Customize"; opens localized consultation modal; collects traveler preferences; validates and triggers confirmation alert.

## Conventions

- **File Naming**: Kebab-case and lowercase semantic names (`index.html`, `styles.css`, `main.js`).
- **CSS Architecture**: Clean CSS custom properties (`--color-*`, `--radius-*`) combined with utility classes.
- **Image Handling**: Strict aspect ratio wrappers with `object-fit: cover` to guarantee zero distortion across viewports.
